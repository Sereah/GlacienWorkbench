# 架构专题资料

按需维护以下专题文档，避免 `AGENT_GUIDE.md` 过度膨胀：

- `configuration.md`：功能域用户数据与迁移。
- `artifacts.md`：APK、签名、资源、文件白名单。
- `device.md`：设备、进程、拉起、广播、平台签名。
- `logs-and-frontend.md`：Logcat、SSE、过滤规则、前端状态。
- `audio-processing.md`：外置 FFmpeg 与多通道 PCM 播放预览。

当前详细总览见上级 `AGENT_GUIDE.md`。当某一专题开始频繁修改时，将相关事实从总览迁入对应文件，并在总览添加链接。
