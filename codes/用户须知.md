# Glacien Workbench 用户须知

Glacien Workbench 是运行在本机的开发工具，服务只监听 `127.0.0.1`。正式桌面包已经包含 Python、Qt WebEngine 和前端资源，普通使用者不需要另外安装 Python 或浏览器。

## 开始前先准备什么

- 使用 ADB 功能必须安装 Android SDK Platform-Tools，其中包含 `adb` 和 `fastboot`。
- APK 签名及签名证书 SHA-256 检查需要 Android SDK Build-Tools 中的 `apksigner`；`zipalign` 建议一并安装。
- 高速离线日志分析需要安装 ripgrep，命令名是 `rg`。没有 `rg` 时仍可使用“浏览器文件夹”兼容模式。
- scrcpy 投屏需要单独安装系统版 scrcpy。Glacien 不内置或分发 scrcpy。
- PCM 音频播放需要单独安装 FFmpeg。Glacien 不内置或分发 FFmpeg。
- Android 设备需要开启“开发者选项”和“USB 调试”，首次连接时在设备端允许当前电脑的调试授权。

安装第三方工具时，优先使用系统包管理器或软件官方发布页。公司电脑还应遵守所在组织的软件安装和数据合规要求。

## 安装 FFmpeg

macOS 可执行 `brew install ffmpeg`，Windows 可执行 `winget install --id Gyan.FFmpeg -e`，Ubuntu / Debian 可执行 `sudo apt update && sudo apt install ffmpeg`。安装完成后运行：

```bash
ffmpeg -version
```

桌面应用可能不会立即继承终端刚更新的 PATH，请完全退出后重新启动 Glacien。仍无法检测时，在“本地工具 → 音频处理”中填写 `ffmpeg` 或 `ffmpeg.exe` 的绝对路径。

裸 PCM 文件没有描述采样参数的文件头。播放时必须选择正确的采样格式、采样率和通道数，否则会出现速度、音调或噪声异常。当前多路 PCM 按交错（interleaved）布局读取：可以把全部通道下混成立体声，也可以提取指定一路生成单声道 WAV 预览；原始 PCM 不会被修改。

## 安装 ADB

### macOS

已安装 Homebrew 时：

```bash
brew install --cask android-platform-tools
adb version
```

也可以安装 Android Studio，在 SDK Manager 的“SDK Tools”中勾选“Android SDK Platform-Tools”。若还要签名 APK，同时安装“Android SDK Build-Tools”。

### Windows

可在 PowerShell 或 Windows Terminal 中使用 WinGet：

```powershell
winget install --id Google.PlatformTools -e
adb version
```

也可以安装 Android Studio，并通过 SDK Manager 安装 Platform-Tools 和 Build-Tools。部分品牌设备还需要安装厂商 USB 驱动；设备一直不出现时，应先在 Windows 设备管理器中检查驱动状态。

### Linux

Ubuntu 或 Debian：

```bash
sudo apt update
sudo apt install adb
adb version
```

Fedora：

```bash
sudo dnf install android-tools
adb version
```

Linux 识别到 USB 设备但没有权限时，通常还需要配置 Android 设备的 udev 规则，然后重新插拔设备。

### 官方压缩包方式

三端都可以从 Android 官方 Platform-Tools 页面下载当前版本：

```text
https://developer.android.com/tools/releases/platform-tools
```

解压后可在“ADB 概览”中配置 SDK 根目录、`platform-tools` 目录，或 `adb` / `adb.exe` 的完整路径，不要求必须修改系统 PATH。

安装完成后建议验证：

```bash
adb version
adb devices -l
```

设备状态为 `device` 才表示已连接并授权；`unauthorized` 表示还需要在设备端确认授权，`offline` 时可尝试重新插拔或重启 ADB。连接多台设备后，必须在 ADB 概览选择本次要操作的设备。

### 无线 ADB

“ADB 概览 → 无线 ADB”支持两类局域网：电脑连接设备提供的热点，或电脑和设备共同连接第三方 Wi-Fi。扫描会合并 ADB/mDNS、热点默认网关和电脑当前 `/24` 网段中开放的指定端口，默认端口为 `5555`。扫描前会自动清理已经失效的 `offline` 无线连接，也可以在结果列表中主动断开在线无线设备。

设备端必须已经开启网络 ADB。传统 TCP 模式可先通过 USB 勾选“先让当前 USB 设备监听此 TCP 端口”；拔掉 USB 后继续使用无线连接。Android 原生无线调试如果使用动态端口，应以 mDNS 发现结果为准。若第三方 Wi-Fi 开启了 AP Isolation、客户端隔离或访客网络隔离，电脑与设备无法互相访问，软件也无法绕过该网络限制。

Android 11 及以上设备可以在“无线 ADB”中的配对区输入系统显示的 IPv4、动态配对端口和六位配对码。配对端口与随后连接使用的端口通常不同；配对成功后请使用发现到的连接服务。配对码只用于本次请求，不会保存到用户数据。

## 安装 ripgrep

ripgrep 的程序名是 `rg`，用于“离线日志分析 → 高速本地来源（rg）”。

桌面版可以在高速来源配置中直接点击“选择文件”或“选择文件夹”，不需要先在终端执行 `pwd`。只有一个普通日志文件时可直接选择该文件；压缩日志需要选择其所在文件夹。保存目录来源时发现压缩日志会先展示文件并请求确认；确认后解压到压缩包所在目录，全部成功后删除原包。冲突或安全校验失败时保留原包且不留下部分文件；开始过滤不会再次提示解压。

### macOS

```bash
brew install ripgrep
rg --version
```

### Windows

使用 WinGet：

```powershell
winget install BurntSushi.ripgrep.MSVC
rg --version
```

如果使用 Chocolatey，也可以执行：

```powershell
choco install ripgrep
```

### Linux

Ubuntu 或 Debian：

```bash
sudo apt update
sudo apt install ripgrep
rg --version
```

Fedora：

```bash
sudo dnf install ripgrep
rg --version
```

Arch Linux：

```bash
sudo pacman -S ripgrep
rg --version
```

终端能执行 `rg`，但 Glacien 仍提示未检测到时，请完全退出并重新启动 Glacien。桌面应用可能没有继承刚更新的 PATH；Glacien 也会检查 Homebrew、Cargo、WinGet、Scoop、Chocolatey 等常见安装位置。

## 安装 scrcpy

### macOS

```bash
brew install scrcpy
scrcpy --version
```

### Windows

```powershell
winget install --exact Genymobile.scrcpy
scrcpy --version
```

也可以使用 scrcpy 官方 GitHub Release 的 Windows 压缩包。解压后，在“设备工具 → 屏幕捕获 → scrcpy 投屏”填写 `scrcpy.exe` 的完整路径。

### Linux

Ubuntu 或 Debian 仓库提供可用版本时：

```bash
sudo apt update
sudo apt install scrcpy
scrcpy --version
```

不同 Linux 发行版的软件版本可能落后；需要新版本时请参考 scrcpy 官方项目的安装说明。安装后，投屏页会自动显示检测到的路径，也允许保存自定义绝对路径。

## 快速开始

1. 打开“ADB 概览”，确认 ADB 状态和设备授权。
2. 同时连接多台设备时，选择本次要操作的目标设备。
3. 在“部署中心”安装或签名 APK、部署资源。
4. 在“应用与进程”查看全部用户/系统应用；点击星标可加入“关注应用”，原有关键词规则也会继续自动匹配。清除数据、禁用和卸载属于破坏性操作，确认包名后再执行。
5. 在“设备工具”进行截图、录屏、投屏和设备文件管理，也可直接进入“日志Pull”或“Bugreport采集”。
6. 在“实时日志”保存过滤方案后开始监听；大体积本地日志优先使用“离线日志分析”的高速 rg 模式。
7. 在“设置”查看当前配置文件和用户数据目录。

所有带输入提示的文本框在内容为空时都可以按 `Tab` 采用提示内容；采用后再次按 `Tab` 会正常移动到下一个控件。

## 用户数据存放位置

程序和用户数据相互分离，升级或替换应用程序不会主动清理这些数据。可以在“设置 → 用户数据目录 → 打开文件夹”直接定位。

- macOS：`~/Library/Application Support/GlacienWorkbench/`
- Windows：`%LOCALAPPDATA%\GlacienWorkbench\`
- Linux：`${XDG_DATA_HOME:-~/.local/share}/GlacienWorkbench/`

该目录可能包含配置、APK、资源包、Keystore、截图、录屏、设备文件下载、日志导出、主题和桌面 Web 配置。Keystore、APK、日志和录屏可能包含敏感或内部数据，不要直接上传到公共网盘、代码仓库或发送给无关人员。签名密码不会持久化。

设备日志 Pull 的新结果不在用户数据目录，而是在系统“下载”目录下的 `device-logs-<当前时间>/` 文件夹。

完整 Bugreport 保存在用户数据目录的 `adb-tools/bugreports/files/`。采集过程使用独立 `runtime/` 临时目录；成功、失败或取消后会清理本次临时目录。

## 导出和导入可分享配置

### 导出或导入全部规则

打开“设置 → 导入或导出全部规则”：

1. 点击“导出全部规则”，保存 `glacien-rules-<日期>.json`。
2. 在另一台电脑上点击“导入规则包”，选择该 JSON。
3. 导入会按功能合并，不会清空其他功能数据。

规则包包含：

- ADB 自定义命令及分类。
- 广播预设。
- 实时日志过滤方案。
- 离线日志过滤方案。
- 日志 Pull 来源规则。

规则包不包含：

- 服务端口、SDK/ADB 路径、scrcpy 路径等本机设置。
- 离线日志的本机目录来源。
- APK、资源包、Keystore、截图、录屏、日志和设备文件。
- 密码、当前设备选择和浏览器显示偏好。
- 用户主题。

外部同名的广播或日志规则会覆盖本地同名规则，导入前页面会要求确认。自定义命令使用融合策略：相同内容跳过，同名但内容不同的命令重命名后并存。

### 单独分享自定义命令

打开“ADB 命令 → 自定义命令”，使用“导出命令”和“导入命令”。这种方式适合只分享命令库；导入会与当前命令融合，不会替换整个命令文件。

### 导出或导入主题

点击侧边栏底部的“主题”：

1. 在主题卡片上点击“导出 JSON”。
2. 修改配色时保持字段名不变。
3. 点击“导入主题 JSON”创建用户主题；相同用户主题 ID 需要确认后才会覆盖，内置主题 ID 不允许覆盖。

用户主题保存在用户数据目录的 `runtime/themes.json`。日志的紫、青、绿、黄、橙、红高亮色是固定日志语义，不属于主题配色。

## 完整备份和恢复用户数据

当前没有“一键导出全部用户数据”按钮。需要保留 APK、资源、Keystore、媒体和全部本机配置时，应手动备份整个 `GlacienWorkbench` 用户数据目录。

完整备份：

1. 完全退出 Glacien，避免复制时配置文件仍在更新。
2. 在设置页记下并打开用户数据目录。
3. 将整个 `GlacienWorkbench` 文件夹复制到安全位置。
4. 按照数据敏感级别保护备份，尤其是 Keystore 和日志。

`runtime/web-profile/` 是桌面 Web 运行配置和缓存，不承载业务规则；只想备份业务数据时可以不复制它。`runtime/migration-backups/` 是升级迁移生成的历史 JSON 备份，可按需要保留。

完整恢复：

1. 完全退出 Glacien。
2. 先备份目标电脑上已有的 `GlacienWorkbench` 文件夹。
3. 将备份内容复制到目标系统的用户数据目录。
4. 启动 Glacien，让当前版本执行必要的数据结构迁移。
5. 重新检查 SDK、ADB、scrcpy、APK 来源和离线日志目录等本机绝对路径。跨系统恢复时这些路径通常需要重新配置。

如果只是与其他用户分享规则，优先使用界面中的规则、命令或主题 JSON，不要分享整个用户数据目录。不要在 Glacien 运行期间把不同电脑的完整数据目录直接合并；同名文件可能覆盖，且本机路径并不通用。

## 升级版本时的数据影响

- 用户数据保存在系统用户数据目录，不在应用安装目录，正常覆盖安装新版本不会删除。
- 新版本只为新增功能补充新的配置域；已有功能继续使用稳定的数据 key。
- 数据结构需要升级时，程序会先把原 JSON 备份到 `runtime/migration-backups/<当前时间>/`，再进行迁移。
- 降级到旧版本可能无法读取新版本数据，不建议用旧版本继续修改已经升级的配置。
- 升级前仍建议完整退出程序并备份用户数据目录，特别是保存了 Keystore、重要规则或大量媒体文件时。

## 操作安全

- 资源部署会清理设备目标目录中的同名顶层内容。
- 卸载应用会删除设备上的应用及其数据。
- Root、Remount、重启设备和设备文件删除会直接改变设备状态。
- 自定义 ADB 命令可能绕过普通页面的保护；执行前确认命令、目标设备和路径。
- 多设备环境中，每次破坏性操作前都应再次确认当前选择的设备序列号。
- 不要把生产签名密码写入命令、规则、文件名或主题 JSON。

## 常见问题

### ADB 已安装但页面未检测到

完全退出并重启 Glacien；仍未识别时，在 ADB 概览填写 SDK 根目录、`platform-tools` 目录或 `adb` 完整路径。

### 设备显示 unauthorized

解锁设备并接受 USB 调试授权；没有弹窗时，可在开发者选项中撤销 USB 调试授权后重新连接。

### rg 已安装但页面未检测到

先在新终端执行 `rg --version`，然后重启 Glacien。浏览器文件夹模式不依赖 `rg`，可作为兼容方案继续使用。

### scrcpy 无法启动

先执行 `adb devices -l` 和 `scrcpy --version`。确认设备已授权后，在投屏页查看自动检测路径；自动检测失败时填写可执行文件的完整路径。

### 升级后看不到原来的配置

先在设置页确认用户数据目录是否与旧版本相同。不要立即删除或覆盖目录；检查是否使用了不同的系统账号、`XDG_DATA_HOME` 或测试用 `GLACIEN_DATA_DIR`。
